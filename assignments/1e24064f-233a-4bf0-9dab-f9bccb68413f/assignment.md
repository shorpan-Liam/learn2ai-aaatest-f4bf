# React 调研报告（200 字）

## 目标

通过自行检索资料，形成一份**不少于 200 字**的 React 调研报告，说明 React 是什么、它解决了什么问题、当前的主流使用情况，以及你对它的初步判断。

建议先读课程资料 `materials/react-introduction.md`，再结合官方文档 <https://react.dev> 与社区信息补充。

## 要求

1. 报告正文**不少于 200 字**（按中文字符计），结构清晰，至少包含以下部分：
   - React 的定位与核心思想（组件化、声明式 UI）。
   - 它解决的主要问题，以及与直接操作 DOM 的方式相比的优势。
   - 当前生态与使用情况（例如常用配套技术：Vite、React Router、Next.js 等）。
   - 你自己的一句话结论：什么场景适合用 React，什么场景不必用。
2. 参考资料的来源要**逐条列出**（标题 + 链接 + 访问日期），至少 2 条，其中至少 1 条为官方文档。
3. 明确区分**事实**与**个人观点**：引用他人结论要标注来源，自己的判断要说明理由。
4. 必须使用课程资料 `materials/react-introduction.md` 作为起点之一。
5. 需要验证的假设：报告中提到的关键结论（如版本号、特性名称、生态现状）要用官方文档核对，避免引用过时或二手错误信息。

## 提交标准

- 成果放在学生自己的分支上，提交时在应用里确认分享本次学习过程。
- 报告文件建议放在 `work/` 下，命名为 `react-research-200.md`（如已有个人目录则放在其中）。
- 报告开头注明字数统计，并说明关键结论来自哪一份资料或哪一次检索，便于老师核对。
- 附上 AI 参与的部分：你向 AI 提了什么问题、AI 的结论中你亲自验证过哪几条、哪几条你不认同。

## 评分关注点（可选）

- 是否真正做了独立检索，而不是直接复述课程资料。
- 字数达标且内容有信息量，没有为凑字数写空话。
- 参考资料真实可访问，事实与观点区分清楚。
- 是否验证了 AI 的结论，并记录了自己的判断与理由。
