# Vue 调研报告（200 字）

## 目标

通过自行检索资料，形成一份**不少于 200 字**的 Vue 调研报告，说明 Vue 是什么、它解决了什么问题、当前的主流使用情况，以及你对它的初步判断。

这次的重点是**和 React 对照着查**：课程资料 `materials/react-introduction.md` 里的每一个概念（组件、Props、State、条件与列表渲染、数据流动），在 Vue 里各自对应什么写法。建议以 <https://cn.vuejs.org> 官方中文文档为主要来源，再补充社区信息。

## 要求

1. 报告正文**不少于 200 字**（按中文字符计），结构清晰，至少包含以下部分：
   - Vue 的定位与核心思想（渐进式框架、响应式数据、单文件组件 SFC）。
   - 它解决的主要问题：与直接操作 DOM 相比的优势，以及**与 React 的关键差异**（例如模板语法 vs JSX、响应式自动追踪 vs 手动 set 状态）。
   - 当前生态与使用情况（例如常用配套技术：Vite、Vue Router、Pinia、Nuxt 等），并说明 Vue 3 与 Vue 2 的现状。
   - 你自己的一句话结论：什么场景适合用 Vue，什么场景不必用。
2. 参考资料的来源要**逐条列出**（标题 + 链接 + 访问日期），至少 2 条，其中至少 1 条为官方文档。
3. 明确区分**事实**与**个人观点**：引用他人结论要标注来源，自己的判断要说明理由。
4. 必须使用课程资料 `materials/react-introduction.md` 作为**对照基准**之一，至少给出 3 组「React 写法 / Vue 写法」的对应关系。
5. 需要验证的假设：报告中提到的关键结论（如版本号、特性名称、Vue 2 是否仍在维护、生态现状）要用官方文档核对，避免引用过时或二手错误信息。

## 提交标准

- 成果放在学生自己的分支上，提交时在应用里确认分享本次学习过程。
- 报告文件建议放在 `work/` 下，命名为 `vue-research-200.md`（如已有个人目录则放在其中）。
- 报告开头注明字数统计，并说明关键结论来自哪一份资料或哪一次检索，便于老师核对。
- 附上 AI 参与的部分：你向 AI 提了什么问题、AI 的结论中你亲自验证过哪几条、哪几条你不认同。

## 评分关注点（可选）

- 是否真正做了独立检索，而不是直接复述课程资料或 AI 的总结。
- 字数达标且内容有信息量，没有为凑字数写空话。
- 参考资料真实可访问（官方中文文档优先），事实与观点区分清楚。
- React 与 Vue 的对照是否准确——有没有写成「看起来对但其实记串了」的对应关系。
- 是否验证了 AI 的结论，并记录了自己的判断与理由。
